# Starbie-PCB-
My starbie PCB project

This is a PCB board with 2 keys a screen and temp and movement sensors.
I made this for half life and to try to learn about how to make PCB boards.
This board works by have buttons and sensors that report information to the processer and then that information is rendered and shown on the screen.
